# Loan Prediction using logistic regression

# Overview

This project uses a logistic regression machine learning model to predict whether a loan application should be approved based on applicant information. The project demonstrates the end-to-end machine learning process including data preprocessing,model training, prediction and evaluation.

# Objectives

1.Explore and preprocess the Dream House Finance dataset.
2.Train a logistic regression classification model.
3.Predict whether a loan application will be approved.
4.Evaluate the model's performance using classification metrics.

# Technologies Used

Python
Jupyter Notebook
Pandas
Numpy
Matplotlib
Scikit-learn

# Machine Learning Workflow

1.Load the dataset
2.Clean and preprocess the data
3.Handle missing values
4.Encode categorical variables
5.Split the data into training and testing sets
6.Train a logistic regression model
7.Make predictions on the test data
8.Evaluate the model's performance

# Results

The logistic regression model achieved an accuracy of 78.8% on the test dataset,demonstrating good performance in predicting loan approval outcomes.
